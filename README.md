# Little Todo List

> A small home for today’s tasks—nothing more complicated than that.

## How to use it

- Write down only the next few things that would make today feel lighter.
- Tick items off when they are done; moving an item is completely fine.
- End the day by choosing one gentle starting point for tomorrow.

## A small note to yourself

A list is here to help you remember, not to make you feel behind.
